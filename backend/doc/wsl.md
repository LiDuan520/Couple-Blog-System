windows安装linux命令
第一步 wsl --install
    若你电脑未安装 wsl 会自动下载并安装 “用于 Linux 的 Windows 子系统 2.6.1”
    默认会下载 Ubuntu 安装完成后会自动打开这个wsl系统
第二步 设置wsl账户
    输入账户和密码，完成账户初始化
第三步 进入ubuntu系统



小技巧 wsl系统的退出和进入
    进入系统 命令行中输入“wsl”
    退出系统 命令行中输入“exit”
